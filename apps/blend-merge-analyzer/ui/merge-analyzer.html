How ignore works Strips junk from every name before grouping — Revit IDs like [5114268], Blender's .001 duplicate tags, name hashes — so two identical objects aren't split apart by a barcode. Wildcards: # = any digit, * = anything. The defaults are a starting point; edit or delete any rule.

How splitters work Tokens the tool must never merge across. Add PT## and PT-01 stays separate from PT-02 even when you've selected a broader group like Fascia. Wildcards: # = any digit, * = anything. This is how you protect finish and material codes from being collapsed together.
