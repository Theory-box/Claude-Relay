Source

Method

Linear amplifies brightness change — simple, but amplifies noise. Phase amplifies displacement instead, so brightness noise is largely left alone.

Stabilize handheld

Estimates whole-frame shake and counter-shifts before magnifying, so jitter isn't amplified. Cancels translation only (not rotation); pans still pass through.

Higher pulls in slower, wider drift as shake to cancel; lower removes only fast jitter.

View

Magnification

Only motion whose rhythm falls between the two cutoffs gets amplified. Slow sway ≈ low Hz, wingbeats ≈ high Hz.

Noise control

Cleans the feed before magnifying: averages each pixel over time where it's still, but passes through where something actually moves, so the static background de-noises without smearing motion.

Amplifies coarser spatial detail (a pyramid level). Higher = less fine-grained noise, but only larger motion survives.

Lower Color removes the coloured speckle (Linear only — Phase is already brightness-driven).

Quality

Lower detail = smoother, less noise, faster. Phase mode is heavier — drop this if the frame rate falls.
