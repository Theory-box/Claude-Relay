Method

Linear amplifies brightness change — simple, but amplifies noise. Phase and Riesz amplify displacement instead, so brightness noise is largely left alone. Riesz is the fast, high-quality phase method — the best all-round pick.

View

Amplified overlays magnified motion on the scene. Motion only shows the bare motion signal. Isolate subtracts a still background. Warp physically displaces pixels along the motion.

Magnification

How strongly to exaggerate the motion. 1× is off.

Fade rate (Isolate) — how fast a now-still object melts into the background. Low = motion lingers longer; high = it fades quickly.

Only motion whose rhythm falls between the two handles is amplified. Drag the band to move it, or a handle to widen/narrow. Slow sway ≈ low Hz, fast flutter ≈ high Hz. Drag the low handle all the way down (~0 Hz) to catch slow drift / any change vs the start. Shared across all modes.

Warp field

Amplify exaggerates motion (crisp). Suppress holds it still — coarse-to-fine flow pushes moving parts back toward rest so sway or jitter freezes (softer, CPU-only).

Field denoise smooths the motion field over time to cut wide-band noise.

Confidence gate — suppresses flow where there's no real texture to track, so noise stops making the warp jitter (phase-inspired). Off = raw flow everywhere.

Phase flow (beta) — estimates motion from contrast-normalized (phase-like) gradients, so low-contrast motion tracks as well as bright edges. Experimental; brightness flow is the stable default.

Clean plate warps a denoised still of the scene instead of the live frame.

Edge-aware smooths the flow along edges but not across them, so moving objects keep their boundaries instead of smearing. Sensitivity sets how sharply it respects edges (needs Flow smooth up to show).

Flow smooth blurs the displacement field directly — quiets jitter, but too much softens motion.

Mesh warp moves the image on a coarse grid so regions stay coherent (a rubber-sheet look) instead of per-pixel smear. 0% = today's warp; grid size sets the coarseness.

Smoothing & noise

Temporal denoise — cleans the feed over time: averages each pixel where it's still, passes through where it moves, so the background de-noises without smearing motion. (Not used by Warp or Riesz.)

Smoothing — blurs the motion signal spatially. A little removes speckle; too much softens the result.

Spatial scale — amplifies coarser detail (a pyramid level). Higher = less fine noise, but only larger motion survives.

Color — lower removes the coloured speckle (Linear only; Phase and Riesz are brightness-driven).
