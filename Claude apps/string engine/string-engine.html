Merge time > 0 gives a bond a weak holding phase where motion can still break it before it commits — that's where selection happens. Merge time 0 fuses on contact and locks in every mistake.

Solid walls occupy the full depth — nothing passes over or under. Fixed walls are pinned; movable ones flex and collide like any strand. Attributes (thickness, stiffness, curl, grow, solid, fixed…) come per-object from the geometry.

Globals · stack on attributes (0 = untouched)

collapseswell

Each global is an offset added on top of every object's own value — spread between objects is preserved. At 0 the sim runs purely on imported attributes. Grow also gives closed shapes outward pressure so they hold instead of caving in.

About

Geometry is a graph: shared vertices stay joined, detached parts float free. Any strand can be a solid wall (nothing weaves past it) and fixed or movable. Built to import from Blender and grow.

+ attracts, − repels. Each object has its own row, so pulls can be one-way. "own body" folds the object onto itself; 0 means it ignores itself.

Connect

This object's free ends (loose strand tips) attract (+) / repel (−) other ends. Turn on endpoint bonding in Physics and attracting ends that touch snap into a link. On canvas: the green circle is each end's snap reach — another end's dot bonds when it enters the circle; the amber band is the collision keep-out (thickness + padding) around the whole object. If the amber holds ends farther apart than the green reaches, they can't bond.

Affinity · groups

Every object's name is its group id. Select an object and use its Interactions rows to set how it attracts (+) / repels (−) each other object and its own body — per-object and directional. Tag a wall to make it a magnet. The affinity view colours by group; click-drag to pull things.
